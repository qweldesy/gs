# GS Avto — сайт автосервиса в Казани

Статический сайт-визитка автосервиса **GS Avto** (Воскресенская ул., 20, Казань).
Чистый HTML/CSS/JS, без сборщиков.

## Источник данных

Весь контент — только из карточки организации на Яндекс Картах:
<https://yandex.ru/maps/org/gs_avto/76475467654/>

- 4 услуги с ценами из витрины: замена масла 900 ₽, салонный фильтр 800 ₽,
  воздушный фильтр 700 ₽, компьютерная диагностика 1 200 ₽;
- 43 вида работ из блока «Виды работ» (без придуманных услуг);
- 47 отзывов — реальные тексты клиентов; рейтинг 4,6 из 87 оценок;
- 9 фотографий из альбома организации;
- адрес, график Пн–Пт 09:00–18:00, особенности (парковка, Wi-Fi, туалет,
  оплата картой, предварительная запись, животные, частичная доступность).

В карточке витрина отмечена как «Давно не обновлялось» — на сайте об этом
сказано прямо, а остальные работы указаны без цен, «по запросу».

## Структура

```
index.html            — страница (семантические секции, JSON-LD AutoRepair)
css/fonts.css         — @font-face Tektur и Inter (latin + cyrillic)
css/style.css         — дизайн-токены, сетки, адаптив
js/main.js            — меню, Motion-анимации, слайдер отзывов, лайтбокс
assets/fonts/*.woff2  — самохостинг шрифтов
img/opt/*.webp        — оптимизированные фото из альбома
img/opt/og.jpg        — обложка для соцсетей
data/                 — исходные данные карточки (отзывы, прайс, список фото)
```

## Дизайн

- Заголовки — **Tektur** (кириллица проверена рендером), текст — **Inter**.
- Телефоны — системный шрифт, без обводок и `-webkit-text-stroke`.
- Палитра: тёплая бумага `#f3f1ed`, графит `#121316`, сигнальный красный `#e01b2f`
  (в тон вывеске GS Avto).
- Референс: <https://ru.pinterest.com/pin/1004232416945489329/> — крупный
  полноэкранный герой, парящая шапка-пилюля, карточки, тёмная полоса,
  кружки-стрелки и воздушная типографика.
- Анимации — Motion (vanilla, CDN) с поддержкой `prefers-reduced-motion`;
  без CDN сайт остаётся полностью читаемым.

## Мобильная версия

- У фиксированной шапки на мобиле отключён `backdrop-filter`, иначе она
  становится containing block и ломает `position: fixed` панели меню.
- Бургер справа (`margin-left: auto`), z-index выше панели, номер — в меню.
- Герой: фото сверху, заголовок и CTA под ним; прайс в одну колонку,
  работы — компактным списком в две колонки.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```
